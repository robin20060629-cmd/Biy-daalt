### Хийсэн ажлын товч тойм
Энэхүү бие даалтаар номын сангийн бүртгэл, ном зээлэлтийн системийг загварчлан хэрэгжүүллээ. **Part A** хэсэгт объектын хандлагат дизайны зарчмууд болон Factory, Strategy зэрэг дизайны хэв маягуудыг ашиглан системийн логик бүтцийг гаргасан. Тухайлбал, хэрэглэгчийн эрх болон хандалтын хязгаарлалтыг (Rate Limiting) уян хатан байдлаар шийдсэн.

**Part B** хэсэгт Node.js болон Express ашиглан RESTful API хөгжүүлж, ном зээлэх болон буцаах үйлдлүүдийг POST endpoint-оор хэрэгжүүллээ. Мөн системийн баримт бичиг болох OpenAPI (Swagger) болон Postman коллекцуудыг бэлтгэж, автомат шалгалтад бэлэн болгосон.

### Ажиллуулах тушаал

### Part A (Library Design)
cd partA
npm install
npm test

### Part B (REST API)
cd partB
npm install
npm start

### Тулгарсан бэрхшээл ба шийдэл

Бэрхшээл: GitHub-ийн хавтасны бүтэц багшийн өгсөн шаардлагатай яг таг нийцэхгүй байснаас автомат шалгалт дээр алдаа заах эрсдэл гарсан.

Шийдэл: Файлын бүтцийг partA болон partB гэсэн үндсэн хавтсанд хувааж, postman болон openapi.yaml файлуудыг шаардлагатай байршилд нь зөв шилжүүлж өгсөн.
